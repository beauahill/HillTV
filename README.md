# HillTV

A personal IPTV player for Apple TV, in the spirit of UHF and Chillio. SwiftUI, tvOS 17+, Xtream Codes login. Built without a Mac: GitHub Actions compiles an unsigned `.ipa`, and atvloadly on a Linux box signs it with a free Apple ID and keeps it refreshed.

## What works in this starter

Xtream login stored in the Keychain. A slim icon rail for navigation that widens when focused, with a dark, blue-accented look. Home with a featured movie, what's live on your favorite channels, continue watching, and rails for movies and series. Search by name across channels, movies and series. Live TV with big pills for Favorites, Sports, News, Movies, Shows, Kids, Music and World, a channel list showing what's on now and how far along it is, and a detail pane with the next few programmes and an optional live preview of the focused channel. In Sports, games show team logos and live scores and tune to the channel carrying them. Categories you never watch can be hidden under Settings > Categories. A guide grid showing the next three hours per channel, for a category or for your favorites. Channel names are shown without the provider's country prefix and quality label, which appear small beside or under the name. Favorites (long-press Select on a channel). Movies with poster grids and detail pages, Series with season and episode lists. Movies and episodes resume where you stopped. Settings with account status, connection count and a player picker. Two playback engines: Apple's AVPlayer (default, HLS and mp4) and KSPlayer (FFmpeg, optional for live channels as raw `.ts`, and used for movie files the Apple player can't open, such as mkv).

The networking and parsing code lives in `Packages/HillTVCore` and has unit tests that run on Linux or macOS. The SwiftUI layer compiles in CI. The current look has not been run on an Apple TV yet; CLAUDE.md lists what to check on the first install.

Scores and team logos come from ESPN's public scoreboard feed, which is unofficial and may change or stop. If it does, Sports shows plain channels. Games are matched to your channels by team and network names, so some will be wrong or missing.

Hidden categories are saved on each Apple TV separately.

Settings has a live buffer size and a live delay choice. They trim the player's share of the delay behind a live broadcast. Most of that delay comes from how the provider packages the stream.

The live preview uses one of your provider's connections while it plays. It is off by default unless the account reports two or more connections, and you can change it under Settings > Live TV preview.

## Layout

```
App/                      SwiftUI app (views, models, player engines)
Packages/HillTVCore/      Xtream client, lenient JSON models, M3U parser, tests
project.yml               XcodeGen spec, AVPlayer only
project-ksplayer.yml      Same project plus KSPlayer
.github/workflows/        CI: core tests on Linux, unsigned IPA on macOS
Tools/make_icon.py        Regenerates the app icon and Top Shelf images
CLAUDE.md                 Notes and roadmap for Claude Code
```

The `.xcodeproj` is generated by XcodeGen and is not committed.

## Building with GitHub Actions

Push to `main` and the workflow runs core tests on Linux, then builds the app on a `macos-26` runner with the newest stable Xcode. Every run uploads the IPA as an artifact. Pushes to `main` also publish a prerelease named `build-N` (the newest 5 are kept), and tags like `v0.2.0` publish a normal release. A tag with a hyphen, like `v0.3.0-rc1`, publishes as a prerelease and leaves the latest release alone.

Every release carries one IPA. This repo sets the variable `USE_KSPLAYER` to `true`, so the builds from `main` and from tags include KSPlayer and have `-ks` in the file name.

A manual run from the Actions tab follows its KSPlayer checkbox exactly: ticked builds with KSPlayer, unticked builds with the Apple player only, whatever the variable says. Manual runs only upload an artifact; they never publish a release. KSPlayer builds take longer because they pull FFmpeg binaries, and the IPA is about 23 MB. In the app, KSPlayer is off until you pick "KSPlayer for live channels" under Settings > Player. It plays live channels as raw MPEG-TS, which runs closer to the broadcast than HLS. Movies and episodes use the Apple player when it can open the file, and KSPlayer for other formats such as mkv, whichever is picked.

Without the `USE_KSPLAYER` variable (a fork, say), pushes and tags build with the Apple player only.

Cost: public repos build for free. Private repos draw on the account's monthly Actions allowance, and macOS minutes cost about ten times Linux minutes, which works out to roughly 200 minutes of macOS build time a month on a free account. A build takes a few minutes, so that's plenty for normal use, but don't loop CI on every tiny commit.

## Installing on the Apple TV with atvloadly

atvloadly runs in Docker on Linux, pairs with the Apple TV over the local network, signs the IPA with an Apple ID, and re-signs it before the 7-day free-account expiry. It needs to be on the same LAN as the Apple TV because pairing uses mDNS; Tailscale alone won't find it.

Give it its own folder so it stays separate from any other compose stack on the box:

```
sudo apt-get -y install avahi-daemon
sudo systemctl restart avahi-daemon
mkdir -p ~/atvloadly && cd ~/atvloadly
wget https://raw.githubusercontent.com/bitxeno/atvloadly/refs/heads/master/docker-compose.yml
docker-compose pull
docker-compose up -d
```

Then open `http://<box-ip>:5533`. On the Apple TV go to Settings > Remotes and Devices > Remote App and Devices, pair from the atvloadly page, then install the IPA.

Use a separate "burner" Apple ID for signing, not your main one. A free Apple ID allows 3 sideloaded apps active at once, and atvloadly will ask for a 2FA code the first time.

Auto-updates: atvloadly follows a repo's releases, not a branch. On its install page open the Source tab and enter this repo as `owner/repo`, or use "Track updates" on an app that is already installed. Tick the pre-release option to get every push to `main` (the `build-N` releases) and release candidates; leave it off to get only full releases. It picks the IPA by file name, which is why each release here has exactly one. For a private repo, add a fine-grained GitHub token with read-only Contents access to this repo in atvloadly's settings.

## Building on a Mac (optional)

```
brew install xcodegen
xcodegen generate                              # or: --spec project-ksplayer.yml
open HillTV.xcodeproj
```

Set your team under Signing & Capabilities, pick the Apple TV as the run destination, and run. Free-account installs from Xcode also expire after 7 days.
