# HillTV

A personal IPTV player for Apple TV, in the spirit of UHF and Chillio. SwiftUI, tvOS 17+, Xtream Codes login. Built without a Mac: GitHub Actions compiles an unsigned `.ipa`, and atvloadly on a Linux box signs it with a free Apple ID and keeps it refreshed.

## What works in this starter

Xtream login stored in the Keychain. A left sidebar for navigation, with a dark, mint-accented look modeled on IPTVnator's TV edition. Home with a featured movie and rails for favorite channels, movies and series. Live TV with a category column, channel list and a now/next panel from the short EPG. Favorites (long-press Select on a channel). Movies with poster grids and detail pages, Series with season and episode lists. Settings with account status, connection count and a player picker. Two playback engines: Apple's AVPlayer (default, HLS only) and KSPlayer (FFmpeg, optional, plays raw `.ts`, mkv, AC3 and DTS).

The networking and parsing code lives in `Packages/HillTVCore` and has unit tests that run on Linux or macOS. The SwiftUI layer has only been checked for syntax, so the first CI run is its first real compile. Expect a fix or two.

## Layout

```
App/                      SwiftUI app (views, models, player engines)
Packages/HillTVCore/      Xtream client, lenient JSON models, M3U parser, tests
project.yml               XcodeGen spec, AVPlayer only
project-ksplayer.yml      Same project plus KSPlayer
.github/workflows/        CI: core tests on Linux, unsigned IPA on macOS
CLAUDE.md                 Notes and roadmap for Claude Code
```

The `.xcodeproj` is generated by XcodeGen and is not committed.

## Building with GitHub Actions

Push to `main` and the workflow runs core tests on Linux, then builds the app on a `macos-26` runner with the newest stable Xcode. Every run uploads the IPA as an artifact. Pushes to `main` also publish a prerelease named `build-N` (the newest 5 are kept), and tags like `v0.2.0` publish a normal release.

To build with KSPlayer, either tick the box when running the workflow manually from the Actions tab, or set the repo variable `USE_KSPLAYER` to `true` to make it the default. KSPlayer builds take longer because they pull FFmpeg binaries.

Cost: public repos build for free. Private repos draw on the account's monthly Actions allowance, and macOS minutes cost about ten times Linux minutes, which works out to roughly 200 minutes of macOS build time a month on a free account. A build takes a few minutes, so that's plenty for normal use, but don't loop CI on every tiny commit.

## Installing on the Apple TV with atvloadly

atvloadly runs in Docker on Linux, pairs with the Apple TV over the local network, signs the IPA with an Apple ID, and re-signs it before the 7-day free-account expiry. It needs to be on the same LAN as the Apple TV because pairing uses mDNS; Tailscale alone won't find it.

Give it its own folder so it stays separate from any other compose stack on the box:

```
sudo apt-get -y install avahi-daemon
sudo systemctl restart avahi-daemon
mkdir -p ~/atvloadly && cd ~/atvloadly
wget https://raw.githubusercontent.com/bitxeno/atvloadly/refs/heads/master/docker-compose.yml
docker-compose pull
docker-compose up -d
```

Then open `http://<box-ip>:5533`. On the Apple TV go to Settings > Remotes and Devices > Remote App and Devices, pair from the atvloadly page, then install the IPA.

Use a separate "burner" Apple ID for signing, not your main one. A free Apple ID allows 3 sideloaded apps active at once, and atvloadly will ask for a 2FA code the first time.

Auto-updates: atvloadly can track a GitHub repo's releases. Point it at this repo and turn on prereleases, and every push to `main` ends up on the Apple TV without touching anything. For a private repo, add a fine-grained GitHub token with read-only Contents access to this repo in atvloadly's settings.

## Building on a Mac (optional)

```
brew install xcodegen
xcodegen generate                              # or: --spec project-ksplayer.yml
open HillTV.xcodeproj
```

Set your team under Signing & Capabilities, pick the Apple TV as the run destination, and run. Free-account installs from Xcode also expire after 7 days.
